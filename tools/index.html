The Workbench

Tools that do the arithmetic.

Four things that answer a question faster than reading can. Two calculators, one visual reference, and a diagnostic index — all free, all working in the browser, none of them asking for an email address.

home/ tools

Everything here runs client-side and stores nothing. The calculators are for the questions that come up mid-bake, when you need a number and not an essay. The Trouble Atlas works the other direction — start from what went wrong and trace back to the cause. If you’d rather learn a technique properly than diagnose one, that’s Techniques.
